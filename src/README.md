# 序章

夜色像一匹浸过墨的绸，缓缓铺过整座城。

街灯次第亮起，把行人的影子拉得很长，又很短。他站在天桥上，望着桥下川流不息的车河，忽然觉得这座他生活了三十年的城市，陌生得像一个从未到过的远方。

口袋里的手机震了一下。是一条没有署名的短信：

> 「有些门，一旦推开，就再没有回头的路。你，准备好了吗？」

他盯着那行字看了很久，久到屏幕自动暗了下去。

然后，他按下了回复键。

# 第一章 序幕

清晨的雨把整条巷子洗得发亮。

她撑着一把旧伞，鞋跟敲在青石板上，发出细碎而清脆的声响。巷子尽头那家 bookstore 还没开门，卷帘门上贴着一张泛黄的告示：「店主外出，归期未定」。

可她分明看见，门缝里漏出一线暖黄的光。

「有人吗？」她敲了敲门。

没有回应。只有雨声，和远处不知谁家收音机里断断续续的老歌。

她正要转身离开，身后的空气却毫无征兆地凉了一下——像是有人，从她背后，轻轻吹了一口气。

# 第二章 启程

火车驶出站台的时候，窗外下起了雪。

他靠在窗边，看着城市一点点退成一片模糊的灰白。背包里那本旧书被他翻了无数遍，书脊已经松了，像是随时会散。

邻座是个老人，一直盯着他手里的书看。

「年轻人，」老人忽然开口，「那本书，我五十年前也读过。」

他愣了一下，把书合上：「您也知道这个故事？」

老人笑了笑，目光投向窗外飞驰的雪原：「何止知道。那段路，我也走过。」

车厢里的灯忽明忽暗，等他再回头，老人已经不见了，座位上只留了一张泛黄的车票，目的地一栏，写着他从未听过的站名。

# 第三章 暗流

湖水很静，静得能照出天上的月亮，也照出湖底那艘沉了百年的船。

她蹲在岸边，把手伸进冰凉的水里。指尖触到的不是水草，而是一截粗糙的麻绳——绳的那一头，没入黑暗，不知系着什么。

身后传来脚步声。是那个一路跟着她、却始终不肯露面的影子。

「你不该来这里。」影子的声音像是从很远的地方传来。

「可我已经来了。」她没有回头，「而且，我知道你是谁。」

湖面毫无预兆地裂开一道缝，月光顺着裂缝淌了进去，像流进了另一个世界。
