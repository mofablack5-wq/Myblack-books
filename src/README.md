# 我的私人小说库

> 一个用 [mdBook](https://github.com/rust-lang/mdBook) 搭建的私人小说 / 文档阅读站。
> 左侧是章节目录，右侧是正文；原生支持手机 / 电脑端适配，右上角可一键切换**夜间模式**。

---

这里放你的小说简介、封面图或作者按。

如果你还没想好简介，可以先留空，直接点左侧目录开始阅读。

## 如何使用这个站点

- **左侧目录**：点击任意章节即可跳转，支持折叠 / 展开。
- **右上角**：
  - 🔍 搜索（全站全文检索）
  - 🌗 主题切换（明 / 暗 / 跟随系统）
  - ☰ 在手机上展开 / 收起目录
- **正文排版**：已针对中文长文阅读做了优化（衬线字体、两端对齐、首行缩进、舒适行距）。

## 如何替换成你自己的小说

1. 把 `src/` 下的 `chapter1.md`、`chapter2.md`、`chapter3.md` 换成你的真实章节。
2. 在 `src/SUMMARY.md` 里增删目录项，格式为 `- [章节标题](文件名.md)`。
3. 重新构建（`mdbook build`）或推送到 GitHub 自动部署。
